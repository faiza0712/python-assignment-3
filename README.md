**# python-assignment-3**
Overview
This assignment demonstrates basic Python programming concepts including loops, control statements, and functions.
**
**Tasks
Task 1: Number Guessing Game
A number guessing game is created using a while loop. The program uses break, continue, else, and the random module.

Task 2: Multiplication Table Generator
A multiplication table from 1 to 10 is generated using a for loop and the range() function.

Task 3: BMI Calculator
A BMI calculator is created using a user-defined function. The program accepts weight and height as inputs and calculates BMI using the standard formula.

Concepts Covered
While Loop
For Loop
Break and Continue
If-Else Statements
Functions
User Input
Random Module
Arithmetic Operations
Conclusion
This assignment provides practical experience with Python loops, control statements, functions, and basic problem-solving.
